What does this check, and what should I do if I find a delegation?

With EIP-7702, a normal wallet (EOA) can sign an authorization that points its account at a smart contract. After that, the contract's code runs whenever the wallet is called. On-chain, the wallet's code becomes 0xef0100 followed by the 20-byte address of that contract. This page reads each address's code with eth_getCode on every selected chain and decodes it.

  • Each chain is separate. A delegation on Base does not show up on Ethereum. Authorizations signed with chain ID 0 can be used on every chain, so check them all.
  • Known wallet (purple): usually fine if you chose it, for example a MetaMask Smart Account or Uniswap wallet upgrade.
  • Unknown contract (amber): look it up on the block explorer. If you did not set it up yourself, treat the wallet as at risk.
  • Known malicious (red): the private key is very likely leaked. Do not send funds to that address. Move anything left to a fresh wallet, using a new seed phrase.
  • To remove a delegation, sign a new 7702 authorization that points to 0x0000…0000. In MetaMask: account menu → Account details → Smart account → Switch back (per network). If the key is compromised, removing the delegation does not make the wallet safe again.

This page only reads public chain data. It never asks you to sign anything. Labels for "known" contracts are a short built-in list, not a full security audit.
