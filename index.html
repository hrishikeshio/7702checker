What does this check, and what do I do if I'm delegated?

With EIP-7702, a normal wallet can sign an authorization that points it at a smart contract. After that, the contract's code runs whenever the wallet is called. On-chain, the wallet's code becomes 0xef0100 plus the 20-byte address of that contract. This page reads each address's code with eth_getCode on every selected network and decodes it.

  • Each chain is separate. A delegation on Base does not show up on Ethereum. Authorizations signed with chain ID 0 work on every chain, so check every network the account uses.
  • Familiar contract (purple): the delegate's address and its deployed code match a built-in fingerprint for that network, for example a MetaMask Smart Account. That identifies the contract. It is not a security audit, and it is only fine if you set it up yourself.
  • Unverified contract (orange): look the delegate up on the block explorer. If you did not set it up, treat the account as possibly controlled by someone else. Don't fund it or use it until you have checked.
  • Reported sweeper (red): the delegate's code matches a sweeper contract reported by a security team (Wintermute, DeFiHackLabs, Blockaid or Relay; each result links to its report). Copies with a different payout address are caught too. Treat the account as compromised. Don't send funds to it, and move anything left to a new wallet with a new seed phrase.
  • To remove a delegation, sign a new 7702 authorization that points to 0x0000…0000. In MetaMask: account menu, then Account details, Smart account, Switch back (per network). If the key is compromised, removing the delegation does not make the wallet safe again.

This page only reads public chain data and never asks you to sign. To run a check, your browser sends each address (and, when delegated, its delegate) to the selected RPC providers, who can link those requests to your IP address. Familiar labels need a matching per-network SHA-256 fingerprint of the deployed code. The sweeper list is short and hand-checked, so an orange result can still be malicious. Results are not a security audit, and an RPC error means that network's result is unknown.
